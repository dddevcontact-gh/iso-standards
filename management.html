Term

Relevant standards:

  • 25000 (guide to SQuaRE)
  • 25001 (planning and management)
  • 25002 (quality model overview)


This section doesn’t describe anything specific about quality management or similar. It’s used to guide how the rest of the standards are supposed to be used throughout the quality management process.


25000 is the main guide to SQuaRE. It explains what each category is and how they relate, the terminology, and the reference model which shows how they feed into each other. The figure on the home page (sourced from 25002) is a good reference if you don’t want to pay for the paper.


SQuaRE is an integrated family, where each standard is part of a section. The model defines what quality means, measurement gives numbers, requirements describe the quality needed, and the evaluation judges the numbers against the requirements. It acts as a replacement for ISO/IEC 9126 and 14598.


25001 talks about the planning and management when specifying the quality requirements and the evaluation of software product quality. Each part needs scoping, resourcing, roles and responsibilities. The standard is useful as it provides requirements and guidance for the process and technical work. Without this, evaluations don’t have any clear purpose, and the measurements have no meaning based on requirements. This makes the process effectively useless.


25002, this site’s main focus, is the standard which talks about how to use the rest of the specific technical standards. It defines a quality model, as well as the quality characteristics / sub-characteristics which compose it. The standards are a guide for how to use the other standards properly. Instead of the previous management and overview standards, it focuses on the more technical aspects of the process, and how each section links together.
